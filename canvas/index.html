How to interpret this

Boundaries of the evidence

  • These are browser sessions, not verified individual patients.
  • Repeat visits, blocked analytics and continuation in another session can change counts.
  • Page milestones use automatic $pageview; explicit events are used for the named actions.
  • A reservation is not a completed visit. Payment-page reach is not payment success.
  • The supplied funnel stops before the assignment’s real end: a completed first visit.
